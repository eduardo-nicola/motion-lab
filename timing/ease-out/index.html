Linear de PowerPoint.

progressotempo

Velocidade constante: começa preguiçoso e bate no fim como um carrinho na parede. Linear é para scrub de câmera, não para UI.

Usar

cubic-bezier(0.16, 1, 0.3, 1) em hover, enter, painel, reveal. Um token só: --ease-out. No GSAP, ease: "expo.out".

Não usar

linear em interface. E o contrário também: ease-out num tween com scrub mente sobre o dedo; lá o certo é ease none.

Reduced motion / sem GSAP

Sem transform: sem .motion o ponto e o chip já estão no destino e o hover muda só a borda. CSS puro, não depende de GSAP.
