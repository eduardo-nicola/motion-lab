No toque não existe hover. Tudo que está aqui é reforço, nunca a única pista: o botão já parece botão e o link já parece link antes do cursor chegar.

Usar

CTA, card clicável, link importante. Transform e cor, sempre com o mesmo estilo em :focus-visible.

Não usar

Texto corrido. Como única pista de interação em touch. A física de puxão é outra pele: Magnetic button.

Reduced motion / sem GSAP

Só cor: sem .motion nenhum transform, a régua fica como borda que muda de cor e a seta não anda. CSS puro, zero JS.
