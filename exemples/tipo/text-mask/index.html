Quando o título precisa de imagem, o tipo faz mask com estado estático, porque a foto só existe dentro da letra.

rolha · a matéria

Grão

A textura de cortiça só aparece dentro das letras: background-clip: text + color: transparent. Sem suporte, a palavra fica creme, legível.

  • uma palavra
  • uma máscara por dobra
  • peso 700 · tracking −0.08em

Usar

Hero com uma palavra curta e grossa, quando a matéria do produto (cortiça, tecido, paisagem) é o argumento.

Não usar

Frases, palavras longas que quebram no mobile, fonte fina (a imagem some). Nunca duas máscaras na mesma dobra.

Reduced motion / sem GSAP

Estático por natureza: fica igual com motion off. Sem background-clip: text, o @supports deixa a cor sólida de fallback.
