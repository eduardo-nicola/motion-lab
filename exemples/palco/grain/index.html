Usar

Em toda página do sistema: um body::before fixo, pointer-events: none, SVG feTurbulence como data-URI. Zero requests.

Não usar

Dentro de div que scrolla (repaint contínuo mata o FPS no mobile). Não animar o grain. Nunca cobrindo form sem pointer-events: none.

Reduced motion / sem GSAP

Mantém: grain é textura, não movimento. Nada aqui depende de JS; o botão só alterna uma classe para comparação.
