# Um sistema de palco

Fundo é palco, não circo. **Um sistema de fundo por página + [[Grain]] opcional.**

Sistemas (escolher um):
- [[Mesh gradient]] — clima, página tipográfica
- [[Particles]] — poeira, palco vazio
- [[Blob aproximado]] — volume orgânico (canvas 2D, rotulado como aproximação)
- [[Lens blur]] — hierarquia ótica sobre foto
- [[Light leak]] — acento analógico sobre foto
- [[Noise displacement]] — matéria em **uma** palavra

Nunca: blob + particles + mesh juntos. Grain nunca dentro de container que scrolla.

Paralelo tipográfico: [[Marquee]] no máximo uma por página; [[Text mask]] no máximo uma por dobra.
