# Fluxo de criação

## 1. Brief
Produto, público, objetivo (captura, venda, marca), referências. Fixar dials (ver [[Como usar este vault]]).

## 2. Conceito
Uma ideia central que a página inteira serve (ex.: [[Oryzo.ai]] = objeto banal vendido como lançamento de IA). Sem conceito, motion vira enfeite.

## 3. Plano de movimento
- Câmera dominante → [[Uma câmera por página]]
- Sistema de palco → [[Um sistema de palco]]
- Tabela seção → técnica → [[Fórmula do movimento]]
- Dependências (`css` / `vanilla` / `gsap` / `webgl`) e fallback
- Mídia necessária → [[Mídia e imagens]]

## 4. Build
[[Esqueleto de página]] + [[Tokens base]] + snippets das notas de técnica + [[motion-kit.js]].

## 5. Auditoria
[[Checklist de entrega]] → testar 375px, 768px, 1440px, reduced motion ligado, GSAP bloqueado (DevTools → block request).
